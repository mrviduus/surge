# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 3.x     | ✅        |
| < 3.0   | ❌        |

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately via [GitHub Security Advisories](https://github.com/mrviduus/LoadSurge/security/advisories/new).
You will receive a response within 7 days. Fixes for confirmed vulnerabilities are released as patch versions and credited unless you prefer otherwise.

## Scope Notes

LoadSurge executes user-supplied delegates against user-specified targets. Running load tests against systems you do not own or have permission to test is the responsibility of the user, not a vulnerability in the library.
